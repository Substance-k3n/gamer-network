# ADR-0001: The MVP is Find Players, not a social network

**Status:** Accepted (2026-10-08)

## Context

The brief describes a social network: feed, posts, clips, groups, game
pages, search. With a few hundred users, a feed looks dead and a "looking
for players" post goes unanswered. Neither tests whether gamers use the
app to find people to play with.

## Decision

The MVP is sign-up, gamer profile, Find Players listings, connection
requests, notifications, the next-day "did you play together?" check-in,
block/report with admin moderation, and listing share pages. Launch in
one city with 2–3 games. Groups stays a "coming soon" tab with a waitlist.

## Alternatives considered

- Build the brief as written: months longer, and the feed hides whether
  the core loop works.
- Launch nationally with every game: spreads 100 users so thin that no
  listing gets an answer.

## Consequences

- The prototype's Home feed is not built. The bottom nav starts at Find
  Players.
- The success measure is "share of listings that end in a game played",
  not sign-ups.
