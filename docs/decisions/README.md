# Decisions (ADRs)

One file per decision, numbered, never renumbered. Write one when a choice
would be expensive to undo or would surprise someone reading the code.
Change a decision by adding a new ADR that supersedes the old one, and mark
the old one `Superseded by ADR-NNNN`.

Template:

```md
# ADR-NNNN: <the decision, as a sentence>

**Status:** Proposed | Accepted | Superseded by ADR-NNNN (YYYY-MM-DD)

## Context

## Decision

## Alternatives considered

## Consequences
```
