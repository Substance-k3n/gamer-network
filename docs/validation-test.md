# Validation test: Find Players by hand

Runs in weeks 0–2, alongside the setup. Costs nothing. Tells us if the
bet holds, which games to launch with and what people filter by.

## Setup

One existing gaming Telegram group (ask the admin first), or a new one
seeded from a campus or gaming centre. Pin this format:

```
#LFG
Game: PUBG Mobile
Mode: Squad, ranked
Rank: Ace
When: Tonight 21:00
Need: 2 players
```

## Each day

- Count `#LFG` posts and replies per game.
- Next day, ask each poster: "Did you end up playing with someone from
  here?" Log it.

## Log

| Date | Game | Posted by | Replies | Played together? | Notes |
| ---- | ---- | --------- | ------- | ---------------- | ----- |

## What we decide from it

- **Games:** the 2–3 with the most posts and replies.
- **Filters:** whatever people keep writing that isn't in the format.
- **Go / rethink:** if almost nobody plays together even when it's
  easy and free, the app won't fix that. Talk to them before building more.
